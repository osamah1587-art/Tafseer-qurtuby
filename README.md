# الجامع لأحكام القرآن — تفسير القرطبي

تطبيق PWA لتفسير القرطبي كاملاً (١١٤ سورة، ٦٬٢٣٦ آية) — نص محقق دقيق (مصدر: قاعدة بيانات Qul/Tarteel لتفسير القرطبي، طبعة دار الكتب المصرية)، بدون OCR.

## الرفع على GitHub Pages
1. ارفع كل محتويات هذا المجلد (بما فيها `data/` و`idx/`) إلى مستودع جديد، مثلاً `tafsir-qurtubi`.
2. من إعدادات المستودع Settings → Pages → فعّل النشر من فرع main، مجلد root.
3. الرابط هيبقى: `osamah1587-art.github.io/tafsir-qurtubi`

## الحجم
- `data/` (النص الكامل لكل سورة): ~76 ميجا غير مضغوطة، لكنها تُحمَّل سورة سورة عند الطلب فقط (lazy load)، مش كلها مرة واحدة.
- `idx/` (فهرس البحث): ~21 ميجا، مقسّم بحسب أول حرف، يتحمّل جزء بجزء حسب كلمة البحث.
- Service Worker يخزّن أي سورة أو نتيجة بحث فتحتها من قبل، فتشتغل offline بعد أول زيارة.

## ملاحظة على الدقة
النص مأخوذ من نسخة محققة رقمياً جاهزة (مش OCR)، فمفروض ما فيهوش أخطاء طباعة/مسح زي اللي حصلت في كتيب الأذكار. لو لقيت أي خطأ إملائي أو سقط في آية معينة، ابعتهولي وأصلحه في ملف `data/surah_N.json` مباشرة.

## هيكل الملفات
```
index.html      الصفحة الرئيسية (شل التطبيق)
style.css       التنسيق
app.js          المنطق (توجيه، عرض السور، البحث)
manifest.json   بيانات PWA
sw.js           Service Worker (تخزين offline)
data/           surahs.json + surah_1.json...surah_114.json
idx/            فهرس البحث مقسّم بالحرف الأول
icons/          أيقونات التطبيق
```
